About the network

blotter.host organizes public records by state so readers can move quickly between local feeds and the full network.

Home Network directory

How it works

Each state lives on its own subdomain, with its own feed of plain-language summaries. The apex site at blotter.host acts as the directory, search hub, and reader gateway.

Readers can login, register, and subscribe from the front door.

The network currently covers {{ACTIVE_STATE_COUNT}} state feeds.

Editorial principles

The goal is clarity over jargon, consistent formatting across states, and simple navigation from state pages back to the network.

Every state feed should be easy to browse, easy to search, and easy to share.
